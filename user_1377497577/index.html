Об игре

«Космический защитник» — мини‑игра, написанная на чистом HTML, CSS и JavaScript без сторонних библиотек. Враги наступают волнами: чем выше уровень, тем быстрее они двигаются. За каждого сбитого врага начисляются очки — красные дают 10, оранжевые 20, зелёные 30. Три промаха — и игра окончена.
