О проекте

АнимеХаб — демонстрационный каталог аниме, собранный в одном HTML-файле без внешних библиотек и фреймворков. Здесь есть поиск по названию и жанрам, фильтр по категориям, сортировка каталога, топ рейтинга, подборка «продолжить просмотр» и встроенный плеер-заглушка с выбором серии, управлением воспроизведением и кликабельной шкалой времени. Все данные хранятся прямо в коде страницы.
